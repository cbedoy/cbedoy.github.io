About

I've spent my career crafting high-quality, maintainable code and building native mobile applications — first on Android and iOS, today mostly with Kotlin, Jetpack Compose and Kotlin Multiplatform.

Since 2023 I've embraced AI-augmented development: AI coding assistants like Claude and Kilo Code / Cline live in my daily workflow, helping me ship better software, faster — without trading away code quality.

One of the parts I enjoy most is teaching. I like guiding other engineers, giving honest feedback and helping them do their best work. Beyond the editor, I'm a musician and multi-instrumentalist who composes and produces his own music, and a drone pilot chasing views from above.
